# Text_generator
AI Creative Text Generator 🚀

• An interactive AI application that transforms simple user prompts into creative and meaningful text using a pretrained language model.

About

• This project demonstrates how Generative AI can understand a user's prompt and produce context-aware text.
• A Streamlit-based interface allows users to enter their ideas and generate AI-powered content quickly and easily.

Features

• Prompt-based text generation
• Creative content generation
• Customizable output length
• Creativity control
• Instant AI response
• Clear generated output
• Efficient model loading
• Interactive Streamlit interface

Technologies

• Python
• Streamlit
• PyTorch
• Hugging Face Transformers
• Qwen LLM

How It Works

User provides a prompt
↓
Application processes the input
↓
Tokenizer converts text into tokens
↓
Qwen language model predicts the next tokens
↓
Generated tokens are converted back into text
↓
AI-generated content is shown on the screen

Installation

• pip install -r requirements.txt

Run

• streamlit run app.py

Example

Prompt:
Write a short introduction about Generative AI.

Output:
The AI generates an original response related to Generative AI based on the user's prompt.
